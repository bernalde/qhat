# Factorial development control

Declared after observing both development stages. This is an explanatory
control, not held-out evidence. Freeze the same eight targets, HF state, T=1,
r=100, and exact one-word-once Pauli budget. Complete the 2x2 comparison:
complete flip classes versus individual diagonal words plus complete nonzero
classes; ten adjacent-descent passes versus ten best insertion moves. Each
uses both lexicographic and magnitude starts and the same frozen J_D objective.
The original complete/adjacent and refined/insertion outputs are reused;
the two missing arms run here. No settings depend on new circuit errors.
Every missing-arm candidate is frozen before the first new evolution.

Save only active order metadata: inherited graphs, suffix scores, old schedule
hashes, and inactive orders are removed from these derived designs. Preserve
source target provenance and independently check sums, unit commutation and
number conservation through the published integer actions. Compare all four
arms without claiming statistical independence of coefficient scales.

Candidate source files are copied verbatim from the two prior stages and
hashed. A new driver combines them; neither original run is modified.
