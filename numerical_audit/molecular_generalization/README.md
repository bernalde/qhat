# Prospective molecular-family generalization

This study asks whether the physical-error advantage of full-order cubic insertion transfers to two additional molecular families, and whether full-order simulated annealing improves it at the same total construction allowances. The selected cases are hydrogen fluoride and hydrogen sulfide, with prospectively fixed geometries and valence active spaces. Both are held out from current cubic development; older H2S first-order/retained-Strang use is disclosed in [PRIOR_USE.json](PRIOR_USE.json). No universal never-studied claim is made.

The complete old-case preflight has passed, including numerical replay from its extracted archive. The main protocol is frozen; new-family execution is pending and no prospective physical result is claimed. [PREFLIGHT_ACCEPTED.json](PREFLIGHT_ACCEPTED.json) binds the original producer, exact evidence and later replay.

The arms are the unchanged native Python full-order insertion control, the existing Julia width-eight interior-window refinement, canonical and exact unit-magnitude cheap orders, and a new classical simulated-annealing optimizer written in Julia. Full insertion and annealing use the same complete permutation domain, cubic response J, measured common parent, four starts and 32/64-second total CPU allowances. Loading, owned Julia startup/JIT, scoring, native verification and teardown are charged. Language/backend differences make this an end-to-end comparison rather than an isolated causal test of search strategy.

Annealing uses unrestricted insertion proposals, Metropolis acceptance and geometric cooling, with four chains interleaved by cumulative CPU spending. The immutable CO/CH4 calibration fixes temperatures 0.04155802571112692 and 0.002013694406127226. Scalar signatures preserve every guarded arithmetic summand while reducing repeated cache misses; full basis-state labels and transport remain unchanged. The heap256 setting retains the 512 MiB OS ceiling, and one entry inference boundary reduces cold setup. Neither optimization guarantees a globally optimal order or an approximation ratio.

Implementation evidence includes exhaustive dense identities for 120 small permutations, guarded scalar/cancellation/cache checks, controlled scheduling/entry/refusal checks, and a two-order old-LiH bridge with bitwise-identical cubic columns and unchanged-native score agreement. The accepted preflight contains nine orders, 36 logical rows, 24 distinct circuits, two independent references and three retained raw candidate claims. Both complete annealing calls pass their 32/64-CPU work and native-verification gates.

[Calibration evidence](evidence/calibration_2026-10-30/README.md) preserves all three attempts and 661.83 CPU seconds. [Preflight/startup evidence](evidence/preflight_2026-10-30/README.md) retains the failed pilots, diagnosis, completed pipeline, readable later figure, original archives and all costs. Parameters were not retuned on preflight physical rankings.
