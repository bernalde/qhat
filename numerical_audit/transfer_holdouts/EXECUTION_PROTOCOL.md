# Full transfer-panel execution budgets and gates

This protocol adds the full search/circuit phase to the already frozen chemistry
and reference phases. Those earlier attempts, failures and resource ledgers stay
intact. All prospective cases, states, phases, times, initializers, method search
controls and rotation caps remain unchanged. No transfer ordering error has been
measured when these initial full-study ceilings are recorded.

The practical dependency must attest paired Astra/Argon convergence at a frozen
source revision and the owning workflow's `READY FOR HUMAN REVIEW` handoff.
Preparation authenticates the listed source blobs in Git, the unchanged compiler
and the declared complete-return accounting convention. This verifies source
identity; the coordinator remains responsible for the review judgment and original
review/disposition evidence. The attestation is not formal human approval.
Final publication also requires the verified actual numerical dependency merge.
An implementation-only or missing attestation cannot start the transfer study.

## Initial finite phase ceilings

CPU seconds, wall seconds and output MiB are cumulative per phase:

| Phase | CPU seconds | Wall seconds | Output MiB |
|---|---:|---:|---:|
| Existing unit checks, including all new adapter/runner checks | 120 | 900 | 64 |
| Full representative preflight | 600 | 3600 | 256 |
| Main construction and measurement | 2400 | 14400 | 512 |
| Main independent replay and extracted delivery | 2400 | 14400 | 1024 |
| Reporting, Git delivery and evidence integration | 300 | 1800 | 1024 |

The test allowance is the original input/response test pool, with its consumed
attempts retained. It is not renewed for these new files. The full preflight is
distinct from the completed chemistry-only and reference-only preflights and must
exercise the complete new path. A retry retains earlier outputs and consumes the
same pool. An essential resource shortfall requires an explicit decision; neither
the question nor the declared panel may be reduced to make the run fit.

Every job uses one numerical worker, one thread, CPUQuota=25%, Nice=19,
CPUWeight=5, IOWeight=10, MemoryHigh=448 MiB, MemoryMax=512 MiB and no swap.
Start/resume only above 5.5 GiB available memory; freeze only the owned service
below 5 GiB. Numerical, build, test and reviewer clients remain serialized.
Issue #18's separate proof-memory approval does not enlarge this profile.

## Representative path and feasibility

Use the distinct predeclared LiH1.841 geometry, excluded from the main panel.
Retain all five states, every arm and both caps at the largest declared time,
2.73: 16 outer constructors, 74 unique circuits, 80 logical observations, five
full-H references and 280 arm comparisons. Symmetric warmups use all four method
families with HF input, and five compiler paths per model: current first order,
first-trained first/symmetric, Pauli symmetric and cubic symmetric. Their full
work is charged to the campaign. Measured first-order/cubic/state-aware searches
keep the already frozen nominal controls. All orders and complete/partial exact
traces precede every validation error.

The preflight must cover input/reference authentication and bounded archive
loading, coherent objectives and retained moves, training, maximal affordable
steps, prototype lowering/replay, literal independent objectives and primitive
actions, unfused formulas, DAG resources, all rows/pairs, reports, packaging,
safe extraction and complete payload byte checks. A successful producer exit
alone is insufficient. Partial compilation and any unresolved observations stay
visible rather than disappearing from the full logical panel.

Before the main study, extrapolate training/warmup work by the six model groups
and circuit/reference/decision work by the corresponding full/preflight counts.
Include a declared allowance for the largest main term/unit counts, at least
50% final time/storage margin, observed memory headroom, archive/extraction
copies and Git-delivery storage. The input archive already gives the actual main
domain: six modes throughout, at most 77 terms, 32 complete units and nine sector
entries. Feasibility must fit every unchanged main ceiling before execution;
the operating-system guard still enforces those ceilings if an estimate fails.

## Complete cost and data accounting

The whole preparation timer includes dependency/reference/source authentication,
input copies, state-archive loading, actual warmups, unique ordering constructors,
compilation and metadata. Each ordering and compilation also receives an outer
caller timer so its final returned metadata is included. Nested first-order warm
construction belongs inside cubic cost and is not added a second time when
totalling outer campaign charges.

For standalone tables, charge the training reference and evaluation reference
once each when they differ, or once when they are the same archived state.
Model generation/SCF cost is shown separately and in the from-scratch total.
Actual chemistry/reference generation was performed once and is not multiplied
by logical arms. Physical screening and independent verification are offline
campaign costs. Non-HF compiled resources cover evolution only: quantum
correlated/coherent preparation cost remains unknown.

Complete main counts are 96 measured outer constructors, 1,332 unique circuit
candidates, all 1,440 logical observations, 90 reference evolutions and 5,040
within-setting arm comparisons. Every error, leakage value, floor, loss, tie,
unavailable comparison, exact trace and source/input pin must be delivered.
Required closeout includes independent replay, Git/archive/paper checks, paired
source reviews, publication, separate eligible merges and actual-merge CI.
