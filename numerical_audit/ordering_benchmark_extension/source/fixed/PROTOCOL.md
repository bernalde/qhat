# Fixed and fixed-random ordering controls

All 14 previously frozen molecular Hamiltonians use their recorded Hartree–Fock state, exact affine closure and exact reference at T = 1. Eight development cases are four molecules at two geometry scales. Six prospective follow-up cases are three molecules at two coefficient multipliers (not six independent geometries).

There are 22 deterministic schedules and 60 fixed-random schedules (20 permutations of each of owned blocks, conserving refined classes and individual Paulis). Seeds are 2026100900 through 2026100919. Each random permutation is repeated at every time step and is never selected by its measured accuracy.

Deterministic curves use rotation budgets U times 1, 2, 5, 10, 20, 50, 100, with U the retained consolidated Pauli count. Random controls use 100U. If a schedule emits R Pauli words per first-order step, its step count is floor(B/R). Zero steps is explicitly infeasible. No run exceeds its budget. Parent and literal Hastings schedules retain duplicate words and therefore have fewer time steps at a common budget. The separately measured consolidated Hastings variant provides the efficient implementation of its commuting clusters.

Prospective owned-signed schedules also retain the literal archived flat sequence inside each commuting block. JW signed/magnitude schedules retain the literal archived word order, including original floating-coefficient near-ties. Evolution uses the common exact integer coefficients. This avoids silently changing the frozen baselines when sorting exact integers. Parent magnitude uses descending absolute canonical-parent weight. Owned-parent magnitude reorders existing owned blocks without recomputing ownership. Coloring uses exact commutators with deterministic largest-degree/index ties; individual Pauli coloring uses dense IXYZ lexical indices. Complete-class suffix-l1 greedily removes minimum weighted degree: distinct flip destinations forbid cancellation inside a fixed suffix commutator. Complete-class BCH-l1 uses two exact strict-improvement adjacent passes from lexical class order. Random refined blocks have individual diagonal Paulis and complete nonzero flip classes.

Published controls are independently implemented with explicit completions described in published/PROTOCOL.md. Tranter deplete/equalise rules are applied here to first-order evolution. The first-order full BCH coefficient-l1 insertion is an adaptation, distinct from Tranter's incremental second-order error operator. Hastings' unspecified final parallel-depth ordering is completed lexicographically.

Every schedule preserves the exact target coefficient sum and is frozen before any new circuit error in this campaign. Each result and state is atomically checkpointed, with input, schedule, source and state hashes. Resume verifies the hashes rather than trusting file existence. Each job is limited to 6 GiB address space and one numerical thread. Results distinguish the phase-invariant state error, infidelity, particle-number leakage and spin-sector leakage. Ratios near an error floor are not interpreted as superiority.

Designs retain the original input document's fields for provenance. The new `methods` mapping and `extension_*` fields, together with this protocol and `freeze.json`, define this campaign; inherited `planned_runs`, `orders`, and old schedule hashes describe the source campaign and are not its execution plan. New result rows point to the extension schedule and design hashes explicitly.
