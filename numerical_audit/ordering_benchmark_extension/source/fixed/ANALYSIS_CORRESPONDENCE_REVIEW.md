# Read-only comparison and figure review

Reviewed `analysis/summarize.py`, `analysis/render.py`, `paper/theory/expanded_ordering_benchmarks.tex` and `paper/theory/expanded_benchmark_methods.tex` after fixed completion. The review checks the specified comparisons, statistics and presentation; it does not claim independent validation of every propagated state or of every published-method implementation.

No blocking fairness or arithmetic defect was found. The analyzer rejects incomplete campaigns and duplicate rows, checks actual cost against budget, pairs cases explicitly, and rejects nonfinite complete errors. The primary first-order comparisons use the same target, state, time and rotation budget. This is equal allocated budget; duplicated-parent methods can have different realized work because of the floor on step count. Formula order is reported, and symmetric methods account for declared commuting endpoint fusion.

Win/tie/loss counts use one paired error difference with an absolute tolerance of 1e-12; the three outcomes are disjoint. Error ratios omit comparator denominators at or below that floor and report how many remain. The median of paired ratios is computed, not a ratio of aggregate medians. Fixed-random results compare the candidate to each case's 20-sample median, preserving the sampled distribution and avoiding best-of-20 selection by the measured error. Seven molecular families at paired geometry or coefficient scales must not be interpreted as 14 independent samples; the manuscript makes this limitation explicit.

Least-tested work takes the smallest actual rotation count among tested successful grid points. It does not assume monotonicity, interpolate a crossing, or invent results beyond the budget grid. The threshold scatter omits cases where either method fails the threshold; each label displays the joint-success count, and the manuscript caption explicitly calls these joint-success ratios. Such a plot alone does not establish an all-case cost advantage, but the underlying full errors and censored counts are retained.

The selected headline table and figure are subsets of the complete deterministic table. In particular, symmetric signed-Pauli and complete-class lexical controls appear in the complete table even though the main figure selects magnitude and conserving orders. The manuscript must continue to assess all controls rather than infer global superiority from the selected panel. At budget 100U many second-order errors hit the reporting floor, so the separate 10U within-Strang comparison is more informative for this panel. Its empirical benefit also changes the diagonal partition relative to complete-class lexical order; it is not an isolated test of only the refined unit permutation or a proved second-order objective.

Classical search matching uses objective-evaluation counts, not wall time, and the timing scopes differ across campaigns. The methods appendix correctly states these distinctions. The post-hoc uniform endpoint-fusion sensitivity changes estimated work for already measured states; it is not a rerun at uniformly matched new budgets. The main budget comparison and this sensitivity should remain separately labeled.

The independent fixed arithmetic is in `final_numerical_review.json`; it confirms all 22 deterministic fixed controls and all three random-median comparisons at 100U. Exact reviewed-file hashes appear in `analysis_correspondence_inputs.json`. One typesetting nit was reported to the parent: the main figure caption's opening quotation marks around g and c lacked matching closing quotation marks at review time.
