# Optimized ordering and Strang controls

This is a continuation of the frozen conserving insertion method, with 14 existing molecular targets: eight development geometries (four molecules times two geometry scales) and six prospective cases (three molecules times uniform Hamiltonian coefficient scales 1 and 5/4). No state or target is regenerated. Time is 1, input is Hartree–Fock, and saved exact states are shared with all comparators.

Four first-order arms optimize the refined conserving blocks with JD, those blocks with J0, individual Paulis with JD, and individual Paulis with JD under a matched number of insertion-position evaluations. Each search starts from label order and descending unit coefficient l1 order, accepts at most ten best improving insertions per start, and uses relative improvement tolerance 1e-12 (absolute floor 1e-30). Every possible improving insertion is evaluated using exact integer commutator destination amplitudes and a sum of nonnegative weighted squares. Incremental floating scores are only a screening device, with a conservative floating-roundoff allowance. This avoids accumulated subtraction causing the old strict consistency guard to reject a correct search. It does not use circuit errors.

The matched-budget Pauli arm receives the conserving JD search's total insertion-position evaluation count, split equally between two starts (remainder to the second). If the limit interrupts a sweep, it accepts the best improvement actually examined. This controls search evaluations, not wall-clock time. Setup and search times are reported separately. A sweep counts all possible insertion destinations, including swaps with zero commutator.

Schedules are frozen for all cases before any new propagation. Development refined JD, J0 and unrestricted Pauli JD orders must equal their archived orders exactly. Archived JW signed and magnitude schedules are preserved, including their floating-coefficient tie decisions.

Four second-order controls use the selected conserving JD order, individual-Pauli magnitude order, individual-Pauli signed order, and complete-class label order (including the unsplit diagonal class). Search objectives are not reoptimized for second order. Commuting blocks at the middle of each Strang step and at adjacent step boundaries are merged exactly. For U emitted Paulis per first-order step, endpoint block lengths Lfirst and Llast, and r Strang steps, the number of rotations is r(2U-Lfirst-Llast)+Lfirst. The recorded pulse sequence contains exact integer duration numerators with denominator 2r; every word's total duration is 1.

First-order budgets are U times 1,2,5,10,20,50,100. Strang uses U times 2,5,10,20,50,100 and the greatest feasible integer r. Budget means Pauli rotations, not compiled hardware gates. All methods use the same coefficient target and affine Pauli-invariant closure, retaining canceled-parent terms only to reconstruct the closure. No projection to a fixed particle-number sector is made. Rows include the stable phase-insensitive error 1 minus normalized overlap magnitude, infidelity, normalization and number/spin leakage.

Each design, accepted optimizer sweep, output state and measurement row is checkpointed atomically on durable storage. The all-schedules manifest records source and design hashes; propagation refuses changed plans. The independently written checker verifies objectives and replayed products separately.
