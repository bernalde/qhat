# Published ordering comparisons: frozen conventions

All fourteen cases use the exact committed Hamiltonian, Hartree--Fock state and T=1 reference. No reference evolution errors enter ordering selection. The emitted-Pauli rotation budget is U times {1,2,5,10,20,50,100}, where U is the consolidated target's nonidentity Pauli count. The largest feasible integer step count is used. Zero-step entries are explicitly infeasible. Native Strang merges identical central and step-boundary Pauli rotations, costing 2r(U-1)+1. This is a rotation-count comparison, not a compiled CNOT/depth benchmark.

## Source fidelity

- Tranter, arXiv:1912.07555v1 IV.3--4: repeated greedy maximal independent sets of the incompatibility graph, minimum eligible induced degree, explicit dense-IXYZ index ties. Within each group sort descending coefficient magnitude. `depleteGroups` cycles groups; `equaliseGroups` selects a largest group, then its largest coefficient. The original paper tested second-order energy error. Applying these orders to first-order state overlap is an explicitly changed evaluation setting.
- Tranter Appendix A.1--2: `commutator` minimizes the count of commuting selected terms (starting maximum magnitude); `reverseCommutator` maximizes the count of commuting remaining terms. Coefficient magnitude, then dense-IXYZ index breaks ties.
- Tranter V.2--3, Eq. (11): insert incoming terms by descending magnitude, choosing the position minimizing the **incremental** V2 coefficient-l1 norm. The paper does not specify enough norm implementation details to claim identical original code. We specify this coefficient-l1 variant explicitly. All polynomial arithmetic is exact integer arithmetic with a common positive denominator; leftmost position wins exact ties. The Eq. (4) prefix order is reversed to chronological physical Strang order. A separate arm uses that same order in first-order evolution and is labeled an adaptation. W=-24 V2; the physical effective Hamiltonian for exp(-itH) has correction +t^2 W/24 with this convention, a sign immaterial to l1 selection.
- The BCH1 insertion baseline is our explicit first-order adaptation inspired by Tranter: it minimizes the **full** first-order commutator polynomial's coefficient-l1 norm. It must not be called their published V2 algorithm.
- Hastings, arXiv:1403.1539v2 section 4: diagonal parents, then each hopping orbital pair with its assisted hopping parents, then four-distinct-orbital parents. The paper leaves the final parallel-depth order unspecified; we complete it lexicographically by orbital family and canonical parent index. We evaluate the literal parent expansion and its exact consolidation within contiguous mutually commuting families. These have the same one-step unitary; consolidation reduces duplicate rotation count.
- Tomesh, arXiv:2203.12713 section IV; public source pinned at commit 5797aab6cc9ee9f60bdfa0003102fc16d5a6d2aa: **Tomesh-inspired beam32 adaptation**, not a faithful reproduction. We use deterministic RLF clique partitioning, Christofides metric TSP from section IV-B, cut a longest cycle edge, and retain at most32 partial paths per starting clique in the two-successor connection heuristic. Full changes are stored per design: deterministic ties/input; unlimited integer labels; beam search in place of exhaustive binary trees; positive denominator for zero connections; retain all finalists; Christofides instead of the public implementation's stochastic genetic TSP. The pinned code fails with27 cliques because its alphabet has26 characters and enumerates an exponential binary tree; neither limitation is imposed on this comparison. No copied third-party source is redistributed. Adjacent noncommuting-pair coefficient weights are not anticommutator norms.

## Arithmetic, reproducibility and checks

The initial four-method API is `algorithms.build_published_schedules`. Additional methods are in `extras.py`. V2 C++ uses Boost arbitrary-precision integers, built with `g++ -O3 -std=c++20 -mpopcnt v2_exact.cpp -o v2_exact`. Each accepted incoming term is flushed and fsynced to `accepted.tsv`; input/source hashes must agree to resume. Positive uniform coefficient scaling reuses a complete order only after exact normalized-coefficient equality, scaling cubic diagnostics exactly. Every source, input, schedule and saved state is hashed. Each case has atomic design, per-row state/result, and completion checkpoints. Every campaign freezes all14 designs before propagating its first circuit.

`verify_algorithms.py` compares256 dense Pauli products,14 independent NetworkX explicit-tie groupings,20 full dense BCH1 greedy histories,20 full dense incremental-V2 histories and20 restart checks. Three independent matrix logarithms verify the Eq. (4) reversal and physical sign. All long jobs use one numerical thread and a6GiB address-space cap. Pinned Python3.12 environment matches prior artifacts. New outputs are durable; `/tmp` is not used for result storage.
