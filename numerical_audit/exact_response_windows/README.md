defines three new nine-unit restricted domains and separate physical validation.
The earlier four eight-unit windows remain completed prior evidence; no rerun.

Use Python 3.12 with requirements.txt. Run heavy commands through guarded.py
under the protocol's cumulative allowances and shared-machine memory limits.
Commit scientific source before `study.py prepare` for the main panel. Preflight
is explicitly altered-target feasibility work and cannot replace the panel.
